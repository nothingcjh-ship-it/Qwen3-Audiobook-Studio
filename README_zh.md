## 🔥 为什么选择 Qwen3-TTS Studio?

市面上的 TTS 工具要么功能太单一，要么部署太复杂。**Qwen3-TTS Studio** 专为 **有声书内容创作** 而生，将顶尖的 AI 研究与极致简单的便携化部署结合在一起。

- **🚀 双平台 Turbo 启动**: Mac (M1/M2/M3) 与 Windows (NVIDIA CUDA) 均支持一键环境安装。
- **🎭 角色编排**: 专业的“角色-音色”映射管理，告别繁琐的后期音轨剪辑。
- **🎨 创意捏脸**: 支持通过文字描述设计独一无二的声音，灵感不断档。
- **🛡️ 隐私保护**: 100% 本地运行。无需联网，无需订阅费，你的数据只属于你。

## 🚀 快速开始

### 方法 1: 极简便携版 (推荐) 🎒

#### 🍎 Mac 用户:
1.  **下载 & 解压**: 下载本项目文件夹。
2.  **双击运行**: `launch_studio.command`。
3.  **Turbo 安装**: 脚本将自动在本地创建隔离环境 (`./runtime_env`)，采用 Pip 优化策略即刻完成。

#### 🪟 Windows 用户:
1.  **双击运行**: `launch_studio_windows.bat`。
2.  **显卡驱动**: 自动检测并启用 NVIDIA GPU (CUDA) 加速推理。

---

## 🌟 核心功能

### 1. 🎧 有声书工坊 (Studio Tab)
- **剧本驱动**: 使用标准的 `角色: 对话` 格式即可生成。
- **分组渲染引擎**: 采用 Map-Reduce 策略，通过角色分组减少模型切换开销，提升长篇制作效率。
- **导演标签**: 支持 `[p=x]` 标签（如 `[p=1.5]`），精确控制对话间的留白时间。

### 2. 🎨 AI 语音设计器
- **文字捏声**: 只需描述（如“磁性的中年男低音”），AI 即可为你创造全新的声音。
- **秒速保存**: 设计出满意的声音后，一键保存至 `./voices` 库，立即在 Studio 中调用。

### 3. 🧬 零样本克隆
- **秒速克隆**: 仅需 5 秒音频样本，即可完美还原目标音色。
